# Практика 4 — промпты и клиенты LLM

Реализованы GigaChatClient и OllamaClient с общим контрактом generate(messages, temperature). Для GigaChat температура минимум 0.01, обработаны ошибки, подсчёт токенов через SDK с оценкой при недоступности. Проверка TLS включена. Для Ollama используется /api/chat, stream=false, таймауты; блок think удаляется, незавершённое рассуждение не выдаётся за ответ.

У трёх ролей отдельные системные инструкции: финансовая сверка, раскрытые риски, корпоративные события. Общие правила требуют источник, период и единицы; запрещают инвестиционные рекомендации. Few-shot содержит проверенные значения из таблицы Net debt с условием использовать их только при наличии соответствующего контекста. build_messages собирает system → хронологическая история → фрагменты и вопрос последним.

## Фактические проверки

- SDK-контракт GigaChat проверен mock-тестом. Настоящий GigaChat не проверялся: GIGACHAT_CREDENTIALS отсутствует. Для локальной модели ключ не нужен.
- CPU Ollama 0.11.11 установлена из официального GitHub release; SHA-256 архива и установленных файлов зафиксированы в models.json.
- Реестр Ollama вернул 403. Использована поддерживаемая загрузка GGUF с Hugging Face: официальный Qwen/Qwen2.5-1.5B-Instruct-GGUF, точная ревизия и SHA-256 в models.json. Модель зарегистрирована как iis-bp. Данные, настройки и модели сохраняются отдельно от процессов.
- Пробный DeepSeek-R1 не завершил ответ в пределах лимита; Qwen 0.5B перепутала Finance debt и Net debt в уточнении. Неудачный журнал сохранён в ollama-small-model-failure.log. Эти прогоны не считаются успешной проверкой качества.
- Qwen 1.5B при настоящем сквозном вызове MCP → ChromaDB → Ollama вернула: «На конец 2023 года Net debt BP составляет 20,912 млн долларов США». Значение соответствует корпусу.
- Ответ модели может не соблюдать требование цитирования даже при корректном числе. Наличие инструкции в промпте не гарантирует её соблюдение; полная оценка ответа и защита остаются П6–П7.
- Streamlit проверен AppTest: заголовок отображается, исключений нет; на настоящем backend отсутствует предупреждение fake. HTTP health endpoint вернул ok.

Диалог из трёх вопросов и фактические ответы сохраняются в отчёте П5. Это небольшой smoke-набор, а не оценка качества на десяти вопросах или доказательство отсутствия галлюцинаций.
